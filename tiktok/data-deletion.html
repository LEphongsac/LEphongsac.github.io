Data Deletion Instructions

Last updated: November 2, 2026

L'Énigme demeure Uploader keeps no data on any server. The only stored data is an access token on the owner's own computer.

How to delete your data

  1. Remove the app's access: in the TikTok app, go to Profile → Menu → Settings and privacy → Security and permissions → Apps and services permissions, find "L'Énigme demeure Uploader" and tap Remove access.
  2. Delete the local token file from the computer where the app runs. This removes all stored login data immediately.
  3. Videos published with the app can be deleted from your TikTok account like any other video.

Request deletion by email

You can also send a deletion request to lephongsacyoutube@gmail.com. Requests are handled within 7 days.
