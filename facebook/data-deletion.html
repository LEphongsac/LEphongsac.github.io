Data Deletion Instructions

Last updated: November 2, 2026

Personal Video Uploader for Facebook keeps no data on any server. The only stored data is an access token on the owner's own computer.

How to delete your data

  1. Remove the app's access: on Facebook, go to Settings & privacy → Settings → Apps and websites, find "Personal Video Uploader for Facebook" and click Remove.
  2. Delete the local token file from the computer where the app runs. This removes all stored login data immediately.
  3. Videos published with the app can be deleted from your Facebook Page like any other post.

Request deletion by email

You can also send a deletion request to lephongsacyoutube@gmail.com. Requests are handled within 7 days.
