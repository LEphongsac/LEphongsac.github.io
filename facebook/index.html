Personal Video Uploader for Facebook

This is a small personal tool. It publishes videos that I made to my own Facebook Page, using the official Meta Graph API.

What it does

  • Publishes my own videos and Reels to my own Facebook Page.
  • Sets the title and description of those videos.

Who uses it

Only me, the owner and admin of the Page. It is not offered to other users.
